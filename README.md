# Сборка

Обучалка подбора оборудования HVAC: хладагент, номинал, пульт, вентиляция печи и плата A2L. Каталог — Carrier и Bryant из базы «HVAC Game» (волна 2, 4 октября 2026).

Связка либо проходит, либо останавливается с причиной. Схема клемм рисуется только если стопов нет.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает сервер. По умолчанию это порт 8080.

Это сверка с записями базы, не замена шильдика и мануала на объекте.
